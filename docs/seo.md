# Seo

Each public route has a distinct title, description and canonical URL on https://adaptsphere.ai. Common original 1200×630 Open Graph artwork, favicon, sitemap.xml and robots.txt are generated. Schema uses Organization, WebSite, BreadcrumbList and Article where relevant; no Person schema. Existing URLs have permanent Next redirects. Expand the redirect map against a full WordPress export, sitemap and Search Console before cutover. Never redirect every missing URL to the homepage.

Public WordPress sitemap inventory: 20 URLs covered by preserved routes or explicit redirects; see redirect-inventory.md. Access-log/Search Console URLs still need staging review.
