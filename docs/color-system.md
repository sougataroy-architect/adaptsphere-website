# Color System

Ivory #F6F4EE; white #FFFFFF; subtle surface #EEF1EA; graphite #121917; body muted #4A5852; border #D9DED5; strong border #BFC8BC; forest #2F6F58; forest hover #245644; lime #C7F36B; lime soft #EFF8DC; dark panel #1D2925; inverse muted #D8E8D3. Lime is an accent on dark backgrounds, never low-contrast body text on white. Faint text #58645C is reserved for secondary labels. Focus uses an explicit visible outline.
User palette update: text accent on light backgrounds is Mossy Hollow olive #636B2F; signal text and accents on dark backgrounds use the softer #D4DE95. Original supplied logo and forest button fills remain unchanged.
