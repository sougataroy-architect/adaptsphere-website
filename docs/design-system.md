# Design System

Source Serif 4 provides display and long-form editorial typography; Manrope provides navigation, controls and service labels. Container: 1152px with 32px desktop and 20px mobile inset. Header: 64px. Section rhythm: 96/80/64px. Mobile hero: 44px; desktop hero: 64px. Reusable components live in src/components; content in src/content; utilities in src/lib. Custom semantic diagrams show identity, authorization, tools and evidence. Mobile navigation uses Radix Dialog with keyboard focus restoration. Reduced-motion and print rules are included.
