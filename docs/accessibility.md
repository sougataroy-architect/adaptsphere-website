# Accessibility

Semantic header/nav/main/footer, one primary heading, labelled icons and controls, skip link, modal focus containment, Escape close and focus restoration. Target widths: 1440, 768, 390 and 320px. Reduced motion disables animation and smooth scrolling. Automated axe WCAG A/AA checks supplement keyboard and visual QA; they do not prove full WCAG conformance. See output/playwright for actual verification artifacts and qa-checklist.md for results.
